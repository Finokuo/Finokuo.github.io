常见问题

网页版会被抛弃吗？

不会。网页版与桌面版长期并行维护：网页版刷新即最新、跨平台无门槛；桌面版专注需要原生能力的场景（AI 管理大师、系统通知、离线）。两边共用同一账号与云端数据。

桌面版收费吗？

免费。Fuo Tools 全线（网页版 + 桌面版）都不收费、无广告。

支持哪些操作系统？

首批支持 Windows 10 / 11（64 位）。macOS 与 Linux 版本在路线图上，取决于首批 Windows 版的反馈。

我的数据在两个版本间通用吗？

通用。桌面版与网页版连接同一个云端后端，登录同一账号即可：笔记、待办、习惯打卡、AI 任务台全部同步，行级安全策略也完全一致。

安装时杀毒软件 / 系统提示有风险？

独立开发者的应用没有购买代码签名证书，Windows SmartScreen 首次运行会弹出「Windows 已保护你的电脑」，点击「更多信息 → 仍要运行」即可继续。介意的话，可在正式发布后用本页提供的 SHA-256 校验值核对安装包完整性。
