FAQ · 常见问题

下载之前，你想知道的

AI 管理大师为什么在网页上用不了？
浏览器的安全沙箱不允许网页枚举或操控你电脑、手机上安装的应用——这正是我们做桌面版的原因。 只有真正的本地程序才能安全地「扫描设备上的 AI」并牵动它们干活。网页端保留入口，完整体验请下载桌面版。
我的账号和数据在网页版与桌面版通用吗？
通用。桌面版与网页版共用同一 Fuo 账号体系（Supabase）： 云笔记、办公集待办、习惯打卡与番茄钟数据两端实时同步，登录即用，无需重复注册。
扫描手机上的 AI 是怎么做到的？
扫描手机需在「设备类型」中选择 iPhone 或 Android，并保持手机与电脑在同一网络， 按大师给出的指引完成一次配对授权即可。整个过程点对点进行，不经云端。
支持哪些智能体？没在列表里的怎么办？
内置 29 种主流 AI 的识别与适配：豆包、DeepSeek、Kimi、ChatGPT、通义千问、腾讯元宝、文心一言、讯飞星火、Claude 等； 识别不了的窗口可手动绑定（自动定位输入框与发送键），一样能牵动。没有适配的也欢迎反馈，排期透明。
源码包怎么跑？不想装 Python 怎么办？
解压后进入目录，执行 pip install -r requirements.txt，再运行 python main.py 即可打开管理大师； 想要绿色单文件 exe，双击 build.bat 用 PyInstaller 自动打包。不熟悉 Python 的用户建议等正式安装包（打磨中）。
