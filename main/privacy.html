隐私政策

生效日期：2026-11-13 · 适用于 finokuo.github.io（Fuo Tools）

我们只收集提供服务所必需的数据，不追踪、不画像、不卖给任何人。下文说明每一类数据的用途与去向。

一、我们收集的数据

  • 账号信息：注册时提供的邮箱与用户名。密码由 Supabase Auth 进行单向哈希处理，任何人（包括站长）都无法看到原文。
  • 你创建的内容：云笔记、收藏、文件夹、个人主页简介等，仅用于在你的账号下存储与展示。
  • 本机偏好：主题、侧栏折叠状态、最近使用的工具等保存在浏览器 localStorage 中，不会上传。部分工具（如 JSON 格式化、Base64）在免登录试用模式下，输入与结果也仅存在于本机。

二、数据存在哪里

  • 云端数据托管于第三方服务 Supabase（Postgres 数据库 + Auth 认证）。
  • 所有传输均通过 HTTPS/TLS 加密。
  • 数据库启用行级安全（RLS）：你的笔记、收藏等数据仅对你自己的账号可见，其他用户（包括匿名访客）无法读取。

三、我们如何使用数据

  • 仅用于提供账号登录、云端同步、收藏与展示功能；
  • 不用于广告、用户画像或对外出售；
  • 不会向你的邮箱发送营销邮件，邮箱仅用于登录与找回密码。

四、第三方服务

本站仅使用 Supabase（supabase.co）作为认证与数据托管服务。除此之外，本站不加载任何第三方统计、广告或追踪脚本。

五、你的权利

  • 导出：随时在「设置 → 导出账号数据」导出笔记、文件夹与收藏（JSON 格式）。
  • 修改：可在工作台修改用户名与个人简介。
  • 删除：删除的笔记进入回收站，可随时彻底删除；也可自行清空全部内容。
  • 注销：如需彻底删除账号与全部数据，请通过 GitHub Issues 联系管理员处理。
  • 退出登录：登出后本机将清除登录会话令牌。

六、Cookie 与本地存储

本站不使用追踪 Cookie。登录会话令牌保存在 localStorage（键名 sb-*-auth-token），用于保持登录状态；清除浏览器数据即等同于在本机登出。

七、未成年人

本站不面向 14 周岁以下的儿童，也不会有意收集其个人信息。

八、政策变更

本政策可能随功能更新而修订，修订后将在本页面发布并更新生效日期。

九、联系方式

对隐私有任何疑问，欢迎在 GitHub 提 Issue：github.com/Finokuo/Finokuo.github.io
