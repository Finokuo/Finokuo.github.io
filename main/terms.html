服务条款

生效日期：2026-11-13 · 适用于 finokuo.github.io（Fuo Tools）

一、服务说明

Fuo Tools（下称“本站”）是一个免费的在线效率工具集合与云工作台，提供 JSON 格式化、Base64 编解码、二维码生成、云笔记等工具。本站处于公测阶段，功能可能随时调整、增减或暂时中断，恕不另行通知。

二、账号与安全

  • 注册时请提供真实有效的邮箱，用于登录与找回密码；用户名为站内展示名，需遵守公序良俗。
  • 你有责任妥善保管账号密码。任何通过你密码进行的行为均视为你本人行为。
  • 发现账号被盗用，请立即通过页面「忘记密码」重置密码。

三、用户行为规范

使用本站时，你承诺不进行以下行为：

  • 存储或传播违反法律法规、侵犯他人权益的内容；
  • 对本站或 Supabase 等第三方服务进行攻击、爬取、滥用或干扰；
  • 利用本站存储、分发恶意代码或垃圾信息；
  • 批量注册账号或以自动化方式滥用服务。

违反上述规范的账号，管理员有权采取封禁、删除内容等措施。

四、用户内容与权利

  • 你通过本站创建的笔记、收藏等内容，所有权归你本人。
  • 为提供存储与同步服务，你授予本站仅在你的账号范围内存储、展示这些内容的必要权限。
  • 你可随时在「设置 → 导出账号数据」将笔记与收藏导出为 JSON 文件。

五、数据存储

账号与云端内容存储于第三方服务 Supabase（详见《隐私政策》）。因第三方服务故障导致的数据不可用，本站将尽力协助但不承担赔偿责任。
